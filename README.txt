# Eternal Night — Book I (locked)

Rainbow Rot. Revised gothic dark romance.

The hotel is the threat. Seraphine has a code and a cost. Cassian has a wound and agency. The ending is earned.

## Done means

- Ten chapters, warnings, contents, found history, credits.
- Cover → warnings → contents → I–X → credits.
- Arrow keys and swipe turn pages.
- Opens locally. No install.

## How to open

1. Open `index.html` in a browser.
   Or from this folder: `python3 -m http.server 8765`
   then visit http://127.0.0.1:8765/
2. Enter the night. Read the warnings. Open the book.
3. Left / right arrows (or swipe) turn pages.

To share: zip this folder, or host it on any static site (Netlify, GitHub Pages).

## What this edition changed

- Dual voices (Cassian / Seraphine)
- The house as a third character that files guests in a ledger
- Seraphine does not drink without asking; the hotel steals mornings anyway
- Midpoint: he walks the looping corridor and comes back on purpose
- Heat that changes power (a bite she stops)
- All-is-lost quarrel when dawn does not come
- HEA: they become keepers, not kept

Original files remain in Downloads/crimson-veilhistory.
