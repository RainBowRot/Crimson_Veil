# Crimson Veil

A NightBloom Studio gothic graphic novel.

## How to open

1. Unzip the folder.
2. Open `index.html` in any browser (Chrome, Safari, Firefox).
3. Use Next / Previous, the chapter dots, or the left/right arrow keys.

Works on phone and desktop. No install required.

To share: send the zip, or host the folder on any static site (Netlify, GitHub Pages, etc.).
